# 不忙翻译

鼠标选中即可翻译（非划词），免复制、免粘贴、免切换窗口——阅读外文从未如此流畅。

## 简介

遇到不认识的单词或句子时，传统流程是：选中 → 复制 → 切窗口 → 粘贴 → 查翻译。不忙翻译将它压缩为一步：**选中，双击 Ctrl+C，译文已就位**。

- **零操作** — 不打断阅读节奏，选中即触发
- **零等待** — 停笔 0.8 秒自动翻译，无需点击
- **零切换** — 右下角贴边置顶，目光轻移即可阅读译文
- **自感应** — 输入英文自动译成中文，输入中文自动译成英文
- **多语言** — 支持中文/英文/韩语/日语/俄语/法语/德语 互译

## 快速开始

### 自动安装（推荐）

下载 [不忙脚本盒子](https://www.bm-box.cn)，打开 → 脚本市场 → 搜索「不忙翻译」→ 点击安装。

### 手动安装

依赖：Python ≥ 3.8，PySide2，xsideui

```bash
pip install pyside2 xsideui
python fanyi.py
```

## 启动方式

### 通过盒子部署

- **超级复制触发** — 在任意应用中选中文字，快速按 Ctrl+C+C，脚本自动弹出翻译窗口并填入原文
- **单击启动** — 不忙脚本盒子中单击「不忙翻译」，打开翻译界面手动输入
  
  

### 支持命令行参数传入 JSON 文件路径（兼容盒子触发格式）：

```bash
python fanyi.py
python fanyi.py /path/to/input.json
JSON 格式：`{"data": {"translate_text": ["要翻译的文本"]}}`
```



## 功能一览

| 功能    | 说明                      |
| ----- | ----------------------- |
| 自动翻译  | 输入后停顿 800ms 自动翻译，无需点击按钮 |
| 语言检测  | 输入英文自动切到中文目标，输入中文自动切到英文 |
| 语言互换  | 点击中间互换按钮，交换源语言和目标语言     |
| 源语言选择 | 支持自动识别或手动指定七种语言         |
| 窗口置顶  | 始终显示在最前，贴边屏幕右下角         |
| 异步请求  | QThread 后台翻译，不卡界面       |
| 静默执行  | 无终端弹窗，后台运行              |
